# The Co-operators

> The Co-operators is a Canadian insurance and financial services co-operative, owned by Canadian co-operatives, credit union centrals and farm organizations rather than public shareholders. It writes multi-line property and casualty, home, auto, farm, travel and life insurance alongside group benefits, group retirement and savings, wealth management and institutional asset management, with more than $62 billion in assets under administration and nearly 7,000 employees. Its API posture is partner-gated: there is no first-party developer portal on cooperators.ca, and the only API surface in the group belongs to its embedded-insurance brand Duuo.

Generated by the API Evangelist enrichment pipeline on 2026-07-25. Provider did not publish an llms.txt (probed https://www.cooperators.ca/llms.txt and https://duuo.ca/llms.txt — both 404).

## Read this first

- The Co-operators publishes no self-serve API, no developer portal, no OpenAPI, no SDK, no CLI, no webhooks and no status page. Every candidate developer subdomain fails to resolve in DNS and every candidate developer path on the corporate site returns 404.
- The one real API is the Duuo Platform API — partner-gated embedded tenant and event insurance. Access requires a discovery call, a signed partnership agreement, an assigned Partner Account Manager, issued OAuth client credentials, and a compliance review before go-live.
- Duuo's advertised developer portal, https://developer.duuo.ca/, is a Postman-hosted docs domain that returns HTTP 404 as of 2026-07-25. The collection has been unpublished; Duuo's marketing pages still link to it.
- The OpenAPI in this repo is a DERIVATION by API Evangelist from Duuo's own archived published Postman collection, not a provider-published artifact and not live-verified.
- No ACORD, AL3, ACORD XML, NGDS or CSIO standard is referenced anywhere in the group's public materials, and The Co-operators is not in the public CSIO member directory.

## APIs

- [Duuo Platform API](https://duuo.ca/embedded-partners/): Partner-gated embedded insurance API covering account, quote, payment and policy issuance for tenant and event insurance. OAuth 2.0 client_credentials. Ten documented operations across two strictly ordered product flows. No claims or FNOL surface.
